### Mellemstore fund

- UI-konstanter og formatering duplikeret på tværs af Board, Search, Item og VoiceCaptureModal.
- Ingen automatiserede tests for `roles.ts`, kommentarer eller Firestore-regler.
- TypeScript `any` brugt flere steder, svækker `strict: true`.
- Server-side rate limiting for kommentarer mangler.
- Storage-regler er brede; delte billeder bliver effectively offentlige.
- iOS `UIBackgroundModes["fetch"]` ser ubrugt ud; Android storage-tilladelser er bredere end nødvendigt.
- Dokumentation er split mellem to rod-mapper, svært for nye agenter at finde rundt.
- `CHAT-001-build-status.md` er forældet.

### Lave fund

- `DebugOverlay` er ubrugt; `constants/` og `store/` er tomme.
- Backup-filer (`.native-all-in.bak`) ligger i git.
- Shortcuts-link ikon ("🔗") ved kategori er kryptisk.
- Settings-tab viser rå push token og mangler hjælp/privacy-links.

## 3. Handlingsplan (prioriteret)

### P0 — Stopper produktionsrelease indtil rettet

1. **Fjern Firestore catch-all regel** og deploy per-collection regler for `projects`, `items`, `members`, `comments` baseret på RBAC.
2. **Roter / restrikter Google Translate API-nøglen** i Google Cloud Console; overvej Cloud Function-proxy.
3. **Publicer privatlivspolitik** og angiv URL i App Store / Play Store.
4. **Fjern Firebase config-filer fra git** og injicer dem via EAS build credentials.

### P1 — Rettes før næste build eller umiddelbart efter

5. **Udvid release gate** til at checke alle native dependencies (eller lazy-load dem).
6. **Fix VoiceCaptureModal**: korrekt `ownerId`/`userId` til rolle-tjek, `await onSave`, robust auto-save.
7. **Smoke-test Firestore Security Rules** med owner/admin/editor/viewer og ikke-medlemmer.
8. **Versioner `firestore.rules` og `storage.rules`** i repo og automatiser deploy (AUTO-001).

### P2 — Kortsigtede forbedringer (næste 1-2 sprints)

9. **Onboarding + sample project** — 1-2 velkomstskærme og et seedet "Velkommen"-projekt.
10. **Progressiv disclosure i oprettelsesflow** — grundlæggende metadata først, avanceret (foto/OCR/tildeling) foldet ud.
11. **Delt UI-komponent**: shared item-card, shared status/kategori/formatering.
12. **RBAC-surfacing**: skjul utilgængelige handlinger frem for at disable dem.
13. **Tilføj unit tests** for `services/roles.ts` og `services/comments.ts`.
14. **Rens op**: fjern `.bak` filer, ubrugt `DebugOverlay`, tomme mapper.

### P3 — Strategiske overvejelser før større nye features

15. **Produktidentitets-gate**: afklar om Data Capture v1 er:
    - A) Personlig capture-app med optionel deling
    - B) Letvægts projektsamarbejds-app
    - C) Begge dele, men i klare faser
16. **Context Lists MVP**: hvis godkendt, begræns til statiske lister fra søgning, flueben, deling, auto-status-tilbagekobling. Udskyd dynamiske lister, AI-deduplikering og geofencing.
17. **GEOFENCE-001**: bygges først efter CHECKLIST-001 MVP og deep-link handler er solid.
